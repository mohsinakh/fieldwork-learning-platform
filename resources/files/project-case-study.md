# Project write-up template

Answer these prompts using your own work. Leave out claims you cannot verify.

## Project name
[A short, descriptive title]

## The problem
Who is the project for? What does it help them do? What did you leave out of this version?

## Your part
What did you implement? If other people worked on it, explain which parts were theirs. Describe any AI assistance accurately.

## How it works
Walk through what happens from input to output. Add a small architecture diagram if that would make it easier to follow.

## A design choice
Which approach did you choose? What alternative did you consider, and why did you choose this one?

## How to run it
List the prerequisites and setup steps. Include a safe example input and the expected result. Keep secrets and confidential data out of the repository.

## How you tested it
Describe the tests or evaluation. For a measured result, record the baseline, sample, environment, and metric. Say whether the result came from a prototype or production.

## Where it fails
When does it behave poorly? What should someone know before using it?

## Your next change
Choose an improvement and explain why you would work on it next.

## Links
[Repository]
[Demo, if available]

## Practise explaining it
Give a two-minute walkthrough without reading this write-up. Explain the problem and how the project works. Talk about your contribution, a design choice, and a failure case.
