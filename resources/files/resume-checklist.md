# Resume checklist

Use this list before sending an application. Check each item once you have looked at it.

## Check the role
- [ ] I have read the full description and checked the employer.
- [ ] The responsibilities, experience level, location, and work eligibility fit.
- [ ] I have work or learning examples for the main requirements.

## Read the resume
- [ ] Relevant projects and experience are easy to find.
- [ ] Dates, titles, education, and employment types match my other profiles.
- [ ] I have explained my contribution to team results.
- [ ] I know how every number on the resume was measured.
- [ ] Unfinished work is described as ongoing.
- [ ] Skills, experience, and credentials are accurate.
- [ ] The layout is readable and the file format matches the instructions.
- [ ] I have checked spelling and the text in the exported file.
- [ ] Repository, portfolio, and demo links open when I am signed out.
- [ ] I have saved the resume version I am sending.

## If this is my first job
- [ ] Projects explain the problem, what I built, and how I tested it.
- [ ] Academic work, volunteering, simulations, and internships have the correct labels.
- [ ] I can run, explain, and change the projects I listed.

## If I have work experience
- [ ] Recent work that fits this role has enough space.
- [ ] Bullets explain what I did, what I owned, and any results I can verify.
- [ ] Employer and client relationships are clear.
- [ ] I have kept confidential information out.

## Before sending
- [ ] The company, job title, attachments, and screening answers are correct.
- [ ] A requested cover letter explains how my work fits the role.
- [ ] I have saved the job description and recorded the application.
- [ ] I have noted the employer's timeline or a follow-up date.
