# Phone clipboard application kit

Neeche se apne level ka template lo. Har bracket apni details se bharo. Employer, skills, CGPA aur awards wahi likho jo tumhare hain. Final version aur apne links phone mein save kar lo.

## Fresher intro template

[Your degree or current course] graduate/student applying for [target role]. Built [project] using [tools] to solve [problem]; responsible for [what you implemented]. Comfortable with [skills you can demonstrate]. Education: [degree]; [CGPA or verified award, if relevant]. LinkedIn: [your LinkedIn URL]. GitHub: [your GitHub URL].

## Experienced intro template

[Your specialisation] engineer, currently [actual role] at [actual employer], working on [systems or product]. My contribution includes [specific work], using [tools you use]. Earlier work at [previous employer or project] covered [relevant responsibilities]. Education: [degree]; [CGPA and verified award, if relevant]. LinkedIn: [your LinkedIn URL]. GitHub: [your GitHub URL].

## Links to save separately

LinkedIn: [your LinkedIn URL]
GitHub: [your GitHub URL]

Save LinkedIn and GitHub links as separate pinned clips where your keyboard supports it. Otherwise use Notes or text replacement. Read each job description, choose the right resume, and check every pasted field before submitting.
